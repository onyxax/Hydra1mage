# Hydra1mage — Free Online Image Tools

**Crop, resize, compress, convert, rotate, flip, adjust, add effects, and more — all in your browser.**

> 100% client-side processing. No uploads. No sign-ups. Your images never leave your device.

**Live Demo:** https://hydra1mage.vercel.app
**GitHub:** https://github.com/onyxax/Hydra1mage

---

## Features

| Tool | Description |
|------|-------------|
| **Crop** | Interactive visual editor with preset ratios (1:1, 4:3, 16:9) |
| **Resize** | Scale to any dimensions with locked aspect ratio |
| **Smart Compress** | Auto-optimize file size with binary search |
| **Convert** | 11 formats — PNG, JPG, WebP, AVIF, GIF, BMP, TIFF, ICO, ICNS, SVG, PDF |
| **Rotate** | Any angle — 90° presets or custom slider |
| **Flip** | Horizontal, vertical, or both |
| **Adjust** | Exposure, temperature, tint, highlights, shadows, vibrance, gamma, sharpness |
| **Effects** | 15+ filters — blur, grayscale, sepia, pixelate, emboss, vignette, duotone, oil paint |
| **YouTube Thumbnail** | Extract high-res thumbnails from any YouTube video |
| **Image Info** | EXIF metadata, dimensions, file size, dominant colors |

---

## Tech Stack

- Next.js 16 (App Router, Turbopack)
- React 19 + TypeScript 5
- Tailwind CSS 4
- Cropper.js 1.5 (CDN)
- Lucide React icons
